# 🌈 CSS Studio Pro (CSSG)

> **The Ultimate Visual CSS Design & Gradient Studio by [Oathan Rex](https://oathanrex.github.io/).**  
> Create modern, high-performance CSS gradients, glassmorphism frosted glass, neumorphism soft UI, multi-layer box shadows, and animated CSS buttons with instant Tailwind CSS and PNG wallpaper export.

🌐 **Live Website**: [https://oathanrex.github.io/cssg/](https://oathanrex.github.io/cssg/)

---

## ⚡ Key Features

- 🎨 **Multi-Paradigm Gradient Generator**:
  - **Linear Gradients**: 360° interactive angle dial, precision degree input, quick-angle presets.
  - **Radial Gradients**: Circle vs Ellipse, custom focal positions (center, top, bottom, corners).
  - **Conic Gradients**: 360° rotational color sweeps for dials, color wheels, and conic ray effects.
  - **Repeating Gradients**: Zebra stripes, retro scanlines, and texture patterns.
  - **Mesh / Aurora Gradients**: Organic multi-point blurred color clouds.
- 🧊 **Glassmorphism Studio**:
  - Real-time `backdrop-filter: blur(px)` control.
  - Sub-pixel refractive borders, background opacity, and depth elevation.
- ☁️ **Neumorphism (Soft UI) Studio**:
  - Flat, Concave, Convex, and Inset/Pressed tactile surfaces.
  - Dual light/shadow offset and blur controls.
- 📦 **Box Shadow & Glow Stacker**:
  - Multi-layer shadow stacker for realistic 3D elevation and neon colored glow.
- 🔘 **CSS Button Generator**:
  - High-converting gradient CTA buttons with hover animations (scale, shine, glow, 3D lift).
- 🔤 **Text Gradient Studio**:
  - Hardware-accelerated `-webkit-background-clip: text` gradients with ambient drop shadows.
- 🌟 **40+ Curated Trending Palettes**:
  - Hand-crafted collections: Cyberpunk Neon, Sunset Mirage, Emerald Aurora, Royal Amethyst, Oceanic Horizon, Obsidian Velvet, and more.
- 📋 **Multi-Format Code Export**:
  - Clean Raw CSS
  - Tailwind CSS classes
  - React inline style object
  - Scalable SVG `<linearGradient>`
- 🖼️ **4K PNG Wallpaper Export**:
  - 1-click download of your customized gradient as a full 1080p / 4K high-resolution PNG image.
- 🚀 **100/100 Core Web Vitals**:
  - Zero external font files or render-blocking third-party scripts.
  - Full client-side execution in your browser.

## 🛠️ Tech Stack

- **Framework**: React 19 + TypeScript
- **Bundler**: Vite 8
- **Styling**: Tailwind CSS v4
- **Icons**: Lucide Icons
- **Deployment**: GitHub Pages (`https://oathanrex.github.io/cssg/`)

## 🚀 Local Development

```bash
# Clone the repository
git clone https://github.com/oathanrex/cssg.git

# Navigate into project directory
cd cssg

# Install dependencies
npm install

# Start development server
npm run dev
```

### Production Build & Lint
```bash
# Typecheck
npm run lint

# Production build
npm run build

# Preview build locally
npm run preview
```
